Dispatch — API Documentation

Generated with pdoc. Source: server/

Application

  • main— FastAPI application entry point; all routes and dependency wiring

Agents

  • agents.dispatcher— Task dispatch pipeline; resolves intent → provider command → execution
  • agents.command_builder— Builds provider-specific CLI commands (cursor / claude / shell)
  • agents.copilot_agent— Copilot agent prompt construction and response parsing
  • agents.prompt_refiner— Refines raw user prompts before agent dispatch

Services

  • services.security_analyzer— LLM-based risk classification for terminal commands (SAFE / WARNING / HIGH_RISK)
  • services.llm— Intent parsing via Groq LLM API
  • services.transcription— Speech-to-text via Groq Whisper API
  • services.telegram— Telegram bot helpers: token validation, message sending, typing indicator
  • services.phone_verification— Phone number verification via Twilio Verify API

Database

  • database.models— All Supabase PostgREST operations: users, projects, tasks, sessions, devices, tokens
  • database.sidecar_store— SQLite sidecar store for conversation turns, dialogue state, and command risk records
